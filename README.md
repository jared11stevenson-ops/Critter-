# CRITTER

Mobile-first gladiator-fight game (Godot 4.7, GDScript, Compatibility renderer). Capture critters into Habitat Jars, fight Blood Bouts and Practice bouts, permadeath.

- `v2/` — the game project (open `v2/project.godot`); tests: `bash v2/tools/qa/run_tests.sh`
- `design/v2/` — creator GDD, counterplay, roles, decisions; `design/lore_bible_v12.txt` — lore
- `production/` — roadmap, preflight, polish backlog
- `tools/blender/tripo/` — Tripo GLB → rig-part pipeline (see its README); `tools/source_art/` — source models and sheets
- `tools/package_v2.sh` — builds the release zip (CI: `.github/workflows/build-zip.yml`)
