# Agent 1 (Art) — notes

## Red Reaches world (`game/world/red_reaches/terrain_builder.gd`, class `RedReachesTerrain`)
- Instance with `RedReachesTerrain.new()` (or a Node3D with the script) at the world origin; `build()` runs in `_ready`.
  Structures and scatter use world coordinates, so keep the terrain node at the origin.
- Collision: HeightMapShape3D (layer 1) + structure bodies (layer 1). Rope span deck collision is disabled until
  `set_rope_span_visible(true)`; boulder collision is removed by `break_boulder()`.
- `height_at(x,z)` includes bridge decks (Ochre Span always; rope span only when unrolled).
- Exports: `with_lighting` (adds `CritterLighting` = WorldEnvironment + Sun, preset "reaches"), `with_scatter`,
  `with_structures`, `with_backdrop`, `with_collision`. Turn `with_lighting` off if the level provides its own.
- Structures (`get_structure(id)`): `gate_ring`, `rope_span` (`set_unrolled(on)`), `ochre_span`
  (`set_state("intact"|"braced"|"failing")`, `shake(i)`), `waystation_ruins`, `old_road_marker`,
  `thought_boulder` (`shatter()`), `drill_camp`, `augur_rig` (empty Node3D at boss_pos; boss visuals = creatures/augur_rig.tscn).
- Scatter: painted kit billboards in one MultiMesh (`reaches_scatter.gd`), 3D props (crates, flags, pillars) one
  MultiMesh per kind. Paths, markers, triggers, pickups and structures are kept clear.
- Visual "camera cut": cliffs on the camera side (+Z) of floors are lowered visually only (collision keeps full walls).
- QA: `tools/shot.sh res://game/world/red_reaches/terrain_qa.tscn <out> <shots> 16` (12 stops, 1.2 s apart from 1.4 s).

## Shared art code
- `game/art/world/toon_kit.gd` (`ToonKit`): SurfaceTool helpers + shared toon material (`toon_prop.gdshader` +
  `ink_outline.gdshader` next_pass). `game/world/common/world_lighting.gd` (`CritterLighting`) presets reaches/hub/dusk.

## Camera occlusion fade
- Globals `critter_focus_pos` / `critter_cam_pos` (project.godot [shader_globals]); gameplay sets them every frame.
  Props/structures (toon_prop + ink_outline) and scatter dither-fade between camera and focus. Creatures opt out.

## Creatures (`game/art/creatures/*.tscn`, base `creature_base.gd` = `CritterCreature`)
- Models face -Z; `set_facing(dir)` turns the Body. One merged toon mesh per creature, legs animated in the vertex
  shader (UV2 = leg phase/weight) → 2-4 draw calls each.
- `augur_rig`: markers are built in `_ready` under Body/Pose; use `get_drill_tip()`, `get_core()`, `get_vent(1..3)`
  or `find_child("DrillTip")` etc. `play_attack("heavy")` = `play_drill_slam()`. `set_beam(on, yaw_radians_rel)`.
  `set_phase(1..3)`, `open_vents(on)`, `play_die()` → 2.2 s.
- QA: `game/art/creatures/_qa_creatures.tscn`.

## VFX (`game/art/vfx/<name>.tscn`, script `vfx_oneshot.gd` = `CritterVFX`)
- `setup(params)` before or after add_child (see header for params). `rage_aura.stop()`; `psychic_bolt` never frees.
- `premonition_ghost_material.tres` (additive violet fresnel ShaderMaterial).
- Screen shaders: `tilt_screen.gdshader` (`strength`; ColorRect color alpha = fade to dark, so use Color(0,0,0,0)
  normally), `future_noise.gdshader` (`noise`). QA: `_qa_vfx.tscn` (+ `qa_screen`, `qa_noise` args).

## UI (`game/art/ui/`, theme `critter_theme.tres`)
- Type variations: DarkPanel (PanelContainer), ChoiceButton (Button, parchment), HudLabel, TitleLabel (Permanent
  Marker), SolemnLabel (Cinzel), DialogueLabel (Kalam), NameLabel, TrustBar (ProgressBar).
- Textures generated by `tools/art_pipeline/make_ui.py`; theme by `tools/art_pipeline/make_theme.gd` (run with 4.3
  so no uid attributes). Extra: `cooldown_sweep.png` (grey = clockwise angle from top, for a threshold shader).
- Key art: `key_art_title.png` (1024x576, no text, upper area left free for a title). Render scene `key_art_qa.tscn`.

## Hub (`game/world/hub/hub_visual.tscn`)
- Markers: Hotspot_Table/Gate/Habitat/Codex/Lab, CamFocus_Default, NPC_<id> (mollusk, bramvex, nerit, zephyr,
  nyxaris, pharilux, solmara (in the tidal pool), scarlith (0.12 m, on the Common Table), mara (lab)) each with a
  `Billboard` child. Collision on layer 1. `with_lighting` export. QA: `hub_visual_qa.tscn`.

## Habitat (`game/world/habitat/habitat_visual.tscn`, modules `game/art/habitat/<id>.tscn`)
- Slot_Substrate / Slot_Symbiont / Slot_Climate (ceiling mount, modules hang down) / Slot_Anchor / SpecimenSpot.
- Helpers: `set_module(slot, id)` (slot "Substrate" etc., "" clears) → module node, `set_slot_highlight(slot, on)`,
  `set_thriving(0..1)`, `set_stress(0..1)`. Module API: `set_active(on)`, `set_stress(v)`.
